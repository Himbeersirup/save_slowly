本地数据与备份

你的账单数据只保存在当前浏览器的本地存储中。关闭网页通常不会丢失，但换设备、浏览器、文件路径或清理浏览器数据时，可能无法访问原记录。建议每周导出完整 JSON 备份。

导入会覆盖当前账本，先备份再导入。支持升级前的「慢慢攒」旧版 JSON 数据备份。
