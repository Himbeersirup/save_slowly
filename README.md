# Slowly Save | 慢慢攒

一个简洁、自由、可自定义的个人记账与财务管理网站。

Slowly Save 致力于帮助用户轻松管理日常开销、合理分配收入并养成储蓄习惯，让每一笔消费更加清晰，让攒钱变得简单。

## 核心功能

- **收支管理**：记录日常消费，查看历史账单及月度收支情况。
- **自定义预算**：自由设置收入、消费分类及各类别预算，支持跨月结转。
- **储蓄计划**：创建不同储蓄目标，管理资金的存入与支取。
- **数据管理**：支持本地存储、账单导出及数据备份与恢复。

## 使用方式

网站无需注册或登录，打开网页即可使用。用户可根据个人需求设置收入、预算和储蓄目标，并通过日常记账了解自己的消费习惯。

所有数据均保存在当前浏览器本地，不会自动上传至服务器，也不会跨设备同步，建议定期备份。

## 关于项目

Slowly Save 是一个个人兴趣项目，旨在探索更加简洁、灵活的财务管理方式。

项目由个人构思与设计，借助 **ChatGPT 辅助编程实现**，并将根据实际使用体验持续优化。

# Slowly Save 

A simple, flexible, and customizable personal expense tracking and financial management website.

Slowly Save aims to help users manage daily expenses, allocate income wisely, and develop better saving habits, making spending easier to understand and saving money more manageable.

## Key Features

- **Expense Tracking**: Record daily expenses and review transaction history and monthly financial summaries.
- **Customizable Budgets**: Set income, expense categories, and individual budgets, with support for budget rollover.
- **Savings Goals**: Create savings goals and track deposits and withdrawals.
- **Data Management**: Local data storage, transaction export, and data backup and restoration.

## Getting Started

No registration or login is required. Simply open the website to get started. Users can customize their income, budgets, and savings goals, and track their spending habits through daily expense records.

All data is stored locally in the current browser. It is not automatically uploaded to a server or synchronized across devices. Regular backups are recommended.

## About the Project

Slowly Save is a personal passion project that explores a simpler and more flexible approach to personal financial management.

The project was independently conceptualized and designed, with **ChatGPT-assisted coding and implementation**, and will continue to evolve based on user experience and feedback.
